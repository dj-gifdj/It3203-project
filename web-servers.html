What Is a Web Server?

A web server is both a piece of hardware and the software running on it that stores, processes, and delivers web pages to clients. When a browser requests a page, the web server software listens for that request, locates (or generates) the requested resource, and sends it back using the HTTP protocol.

How a Server Handles a Request

  1. The server receives an HTTP request on a port (usually 80 for HTTP or 443 for HTTPS).
  2. It reads the request line and headers to determine what resource is being asked for.
  3. For a static file (like an image or an HTML page), it reads the file from disk and returns it.
  4. For a dynamic request, it may run server-side code (PHP, Python, Node.js, etc.) to build the response, often by querying a database.
  5. The server sends back an HTTP response with a status code (such as 200 OK or 404 Not Found) plus the requested content.

Static vs. Dynamic Content

Static Web Servers

Return files exactly as they are stored on disk — no processing involved. GitHub Pages, which hosts this very project, is a static web server.

Dynamic Web Servers

Generate content on the fly using server-side scripts and databases, producing a different response depending on the request (for example, a logged-in user's dashboard).
