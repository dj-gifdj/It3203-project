What Is a Web Browser?

A web browser is client software that requests resources from web servers and renders them for a human to read and interact with. The browser is responsible for turning raw HTML, CSS, and JavaScript into the visual page you see on screen.

What Happens When You Load a Page

  1. You type a URL or click a link, and the browser resolves the domain name via DNS.
  2. The browser opens a connection to the web server and sends an HTTP(S) request.
  3. The server responds with HTML, which the browser parses into the DOM (Document Object Model).
  4. Linked CSS files are parsed into the CSSOM and combined with the DOM to figure out how each element should look and where it goes.
  5. JavaScript runs, which can further change the page's content or behavior.
  6. The browser paints pixels to the screen, and the page becomes visible and interactive.

Core Browser Components

Rendering Engine

Parses HTML/CSS and draws the page (e.g., Blink, Gecko, WebKit).

JavaScript Engine

Executes JavaScript code (e.g., V8 in Chrome, SpiderMonkey in Firefox).

Networking

Handles HTTP/HTTPS requests, caching, and cookies behind the scenes.

UI Shell

The address bar, tabs, bookmarks, and other elements surrounding the page itself.
