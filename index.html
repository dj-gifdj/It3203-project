Project Abstract

Every time you load a web page, two very different programs quietly cooperate to make it happen: a web browser running on your device, and a web server running somewhere else on the internet. This site explores how those two pieces work together — the request/response cycle, the protocols involved, and the software that powers each side — using plain-language explanations, diagrams, and a glossary of key terms.
